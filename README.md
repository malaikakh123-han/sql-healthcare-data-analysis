# SQL Healthcare Data Analysis

## Overview

This project analyzes a hospital management database using SQL to explore relationships and patterns across patients, doctors, appointments, hospitals, departments, prescriptions, and rooms.

The project includes a series of SQL queries designed to answer practical healthcare management and business questions.

## Database Areas

The analysis covers:

- Patients
- Doctors
- Hospitals
- Departments
- Appointments
- Prescriptions
- Medications
- Rooms

## SQL Skills Demonstrated

- SELECT statements
- JOINs
- LEFT JOINs
- GROUP BY
- HAVING
- CASE statements
- Common Table Expressions (CTEs)
- Window functions
- ROW_NUMBER()
- DENSE_RANK()
- Aggregate functions
- Date functions
- Conditional filtering
- Data aggregation

## Analysis Examples

The project includes queries analyzing:

- Appointment volumes
- Doctor performance
- Hospital activity
- Patient appointment frequency
- Returning patients
- Patient specialty visits
- Prescription activity
- Department room capacity
- Appointment trends over time
- Emergency appointments
- Doctor rankings within hospitals

`Healthcare_Data_Analysis.sql`
